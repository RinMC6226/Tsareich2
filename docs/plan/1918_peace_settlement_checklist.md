# 1918年講和 検討事項リスト（チーム討議用）

史実のパリ講和会議（1919–20）の論点を参考に、Tsareich2 世界線（戦勝：独露伊／敗戦：仏英／解体：墺洪・オスマン）で決めるべき事項を整理する。
確定したら `docs/prehistory/events/1918_peace-settlement.md`（canon）へ反映する。

## 0. 正典（events/ canon）で既に確定している前提 — 再討議不要

討議は以下と矛盾しない範囲で行う（変更したい場合は canon の改訂を伴う）。

- **参戦陣営**: 独露伊 対 英仏墺土。日本は日英同盟に基づき英側で**限定参戦**（極東防衛主軸）→ 日本も広義の敗戦側（`1914_great-war-outbreak.md` / `1918_hara-cabinet-fall.md`）
- **開戦日**: 日本側原文は 1914.7.28（史実通り）。世界線全体の開戦日として確定するかは to_do
- **墺洪・オスマンの解体は1918年講和と一体**。旧墺洪領には「複数の民族国家」が成立。旧オスマン領では海峡・アルメニア・メソポタミア・シリアをめぐり独露の影響力が拡大（`1918_post-war-order.md`）
- **イタリアの獲得物は確定済み**: トレンティーノ／イストリア／ダルマチア沿岸の一部／アルバニアへの影響権／リビア支配の承認（`1918_italy-postwar-nationalist-turn.md`）
- **講和秩序の主導権は独露**。イタリアは「不満足な勝者」として反革命的国家主義王国化（同上）→ 会議の序列は「独露の二巨頭 + 周縁の伊」が正典
- **ドイツは1918年末に憲法改革**: 以後、宣戦・講和・重要同盟に帝国議会と連邦参議院の承認が必要（`1918_german-constitutional-reform.md`）→ 講和条約自体は改革「前」の旧体制下で調印された時系列になる点に注意
- **モロッコは1906年議定書以来「国際監督下」**（`1905_first-moroccan-crisis-tangier.md`）: 仏の関与は警察・財政改革に限定済み → 1936年のモロッコ独立（MOR/RIF）は講和での新規剥奪ではなく、1906年体制の延長として説明できる
- **ドイツは1911年に既にアフリカで対仏補償を獲得**（`1911_second-moroccan-crisis.md`）→ 独領アフリカ（DWA等）の一部は講和以前からの取得。講和での植民地分配と二段構えで説明する
- **ボスニア・ヘルツェゴヴィナは1908年に墺洪が併合済み**（`1908_austria-hungary-defection.md`）→ 墺洪解体時の処分対象に含まれる。ユーゴスラビア成立の線引きに直結。露は1908年に「セルビアと正教徒保護」を掲げて併合を批判した経緯があり、露が南スラヴ国家を後援する動機は canon に既にある
- **オスマンの協商参加動機は「黒海・海峡・カフカスでの露の圧力への恐怖」**（`1914_great-war-outbreak.md`）→ 海峡・アルメニア処分は露の宿願実現として書くのが筋
- **スペインは大戦不参加**（参戦陣営の canon に SPR なし）かつ**1920年代前半に「モロッコ戦争の失敗」で王政崩壊**（`1920_spanish-second-republic.md`）→ 講和のモロッコ処分は、講和後もスペインがモロッコで戦争し敗北する余地（スペイン領モロッコ／リーフ）を残す形でなければならない
- **アメリカの大戦への関与は canon に一切記述なし**（USA 初出は 1929 恐慌・1936 選挙）→ 米は中立だったと扱うのが安全。§3「米の仲介」案は可能だが canon 新設になる
- **満州・朝鮮の露衛星化＋遼東半島占領は1905年ポーツマス条約の帰結**（`1904_russo-japanese-war.md`）→ 1918年講和の対日条項とは切り分けて扱う

### canon と実装マップの矛盾（討議で解消すべき）

- [ ] **イタリアの獲得リストに「コルシカ」「チュニジア」が無い**。canon イベントはトレンティーノ等を列挙するが、実装では ITA がコルシカを領有・チュニジアを衛星国化し、FRA.md（draft）もコルシカ割譲を記述。canon 側へ追記するか、獲得経緯を別建て（講和後の取得？）にするか
- [ ] **オーストリアの扱い**。canon は「旧墺洪領に複数の民族国家が成立」とするが、実装では AUS が state 0（オーストリア本体はおそらく独領）。「独墺合邦」は canon に存在しない → 独によるオーストリア併合を講和に明記するか、canon の「複数の民族国家」と両立する説明（独へ編入もその一形態）を取るか
- [ ] **対日処理の有無**。日本は敗戦側だが、実装では本土16州 + 台湾傀儡を保持し領土喪失なし（満州・朝鮮の露衛星化は1904年日露戦争の帰結）。1918年講和に対日条項があったのか、日本は講和会議に呼ばれたのかを確定（JAP前史の「国際的地位低下」「戦争責任問題」の具体化）
