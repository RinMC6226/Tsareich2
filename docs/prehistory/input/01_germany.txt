# 独露協調の固定化

1905年3月31日、皇帝ヴィルヘルム2世はタンジールを訪問し、モロッコのスルタンの独立と列強の経済的機会均等を支持した。これは、フランス外相テオフィル・デルカッセが進めていたモロッコ支配に対する挑戦であり、ドイツ帝国は国際会議による解決を要求した。史実ではアルヘシラス会議でドイツは孤立したが、この世界では独露再保障条約の延長によってロシア帝国がドイツを支持し、会議の構図は大きく変化した。1906年4月の議定書により、フランスはモロッコ警察・財政改革への関与を認められたものの、その行動は国際監督下に置かれた。これによりドイツは外交的勝利を収め、独露協調は「フランス封じ込め」の国家方針として固定化された。一方、この事件は英仏協商を単なる植民地調整から、反独政治連携へ発展させる契機ともなった。 

# オーストリア＝ハンガリーの離反

1908年10月、オーストリア＝ハンガリー帝国がボスニア・ヘルツェゴヴィナ併合を発表すると、バルカン情勢は急速に緊張した。ベルリン政府は、ビスマルク以来の対露協調を優先し、ウィーンへの全面支持を避けた。ロシアはセルビアと正教徒保護を名目に併合を批判し、ドイツはロシアとの協議を通じてオーストリアに妥協を求めた。これにより、ウィーンではドイツへの不信が拡大した。以後、オーストリア＝ハンガリーはロシアの南下を最大の脅威とみなし、イギリス・フランスとの接近を強めていった。ボスニア危機は、独露同盟が単なる秘密協定ではなく、バルカン秩序を左右する大陸政策へ発展したことを示す事件となった。 

# 皇帝外交の後退

同年10月、デイリー・テレグラフ事件が発生した。ヴィルヘルム2世は英独関係の改善を意図して発言したが、記事はイギリス世論の不信を深め、ドイツ国内でも皇帝の個人的外交への批判を招いた。帝国議会では中央党、社会民主党、進歩派が、外交政策における宰相と外務省の責任明確化を求めた。この事件により、ヴィルヘルム2世の威信は傷ついたが、同時に独露協調は皇帝個人の判断ではなく、宰相府・外務省・参謀本部によって管理される国家政策へ移行した。これにより、独露同盟はより制度的な外交路線として維持されることになった。

# 海軍競争と第二次モロッコ事件

1911年の第二次モロッコ事件では、ドイツ海軍の砲艦派遣とフランスのモロッコ内政介入をめぐり再び緊張が高まった。外務長官アルフレート・フォン・キーデルレン＝ヴェヒターは、フランスに圧力を加えつつも、ロシアとの協調を損なわない範囲で交渉を進めた。ドイツはアフリカで一定の補償を得たが、英独海軍対立はさらに深まった。ティルピッツら海軍派は、英仏協商がドイツの通商と植民地政策を封じ込めようとしていると主張し、海軍拡張論を強めた。これにより、独露同盟は大陸安全保障の枠を越え、英国海洋覇権への対抗軸としても機能するようになった。

# 帝国議会と国内対立

1912年1月12日の帝国議会選挙では、社会民主党が最大勢力となった。工業化と都市労働者層の拡大はSPDの躍進をもたらしたが、宰相は依然として帝国議会ではなく皇帝に責任を負っていたため、議会多数派が内閣を組織することはなかった。SPD内部では、独露同盟をめぐる対立が生じた。労働組合系の穏健派は、独露協調を二正面戦争回避の現実外交として黙認した。一方、ローザ・ルクセンブルクやカール・リープクネヒトに近い左派は、ツァーリズムとの提携を反動的外交として批判した。1912年選挙でSPDが帝国議会最大党となった点は史実とも一致しており、この世界でも社会民主主義の伸長は自然である。 

# ツァーベルン事件と開戦前夜

1913年のツァーベルン事件は、軍部と文民社会の対立を露わにした。アルザス＝ロレーヌで軍人と市民の衝突が起きると、帝国議会では軍の越権行為が激しく批判された。参謀本部は西部国境防衛を理由に軍権強化を主張したが、中央党と社会民主党は文民権利の侵害を批判した。この対立は、翌年の開戦時に「城内平和」によって一時的に覆い隠された。しかし、戦時協力の代償として議会改革要求は残り、後の1918年改革へつながっていった。1914年、バルカン危機、露墺対立、英独海軍競争、仏独対立が重なり、ヨーロッパは独露伊陣営と英仏墺土陣営の全面戦争へ突入した。
