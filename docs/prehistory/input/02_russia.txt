# 独露干渉
1895年、日本は下関条約によって遼東半島を確保したが、この動きに事前に警戒感を示していたロシア帝国政府は、列強諸国に干渉の協力の意思を問うた。しかし、イギリスは不干渉を示し、フランスは特段の興味がないとして、独露二国での実行となる。
独露二国から日本に示された「差し迫った懸念」に対し、日本では陸軍高官が強く反発。二度の交渉の末日本はロシア、ドイツに対して返還の拒否と軍事的現状維持を通達。
1896年、日本は遼東半島の支配の正当化のため現地の整備に力を入れる。これに対し早期の軍事的強硬策をロシアは考慮するが、シベリア鉄道未成ゆえに陸軍力の行使は不可能と判断。ドイツもこの判断に追従した。
しかし、ロシア極東艦隊は装甲巡洋艦ルーリク含む5隻で威圧航行を行い、日本側の巡洋艦や哨戒艦複数とにらみ合いをする「日本海危機(1896)」が発生。
直接の武力衝突は発生しなかったが、地域の軍事的緊張は極めて高い状態となる。また、日本は遼東半島の防衛に国力を大きく割くため朝鮮進出が遅れることとなる。

# 満州権益
ドイツ・ロシア二か国は共同して清に広範な権益を要求。東清鉄道敷設権をはじめとする広範な満州権益をロシアが得るが、日本はこれに対して強く反発し、満州方面へより多くの陸軍を配置した。

# 義和団の乱
義和団の乱では日本が遼東半島防衛に軍力を大きく用いているため、派兵は3000人程度になる。ロシアは7000人規模の大規模な派兵を行い、極東での強い影響力を保とうとした。義和団の乱では日露独英を主とする連合軍と義和団が戦闘し、北京議定書が締結された。議定書においてはロシアとドイツの中国権益が明文化された。これを強く警戒した日本とイギリスは接近することとなった。

# 日露戦争開戦前夜
1903年、ドイツ鉄道事業からの大規模な資本投入によってシベリア鉄道が完全に開通、ロシアべぞは極東方面での大規模な軍事作戦が可能となる。これによってロシア帝国内ではアレクサンドル・ベゾブラーゾフをはじめとする陸軍関係者が日本との開戦を強く要求した。
日本はロシアに対して満州撤退と朝鮮への影響力拡大中止を強く要求するが、ロシアはこれを拡大しつつある極東戦力を根拠に拒否。
1904年、日本はロシアに対して国交断絶を通告し、日露戦争が開戦した。

# 日露戦争
旅順は日本によってある程度要塞化されているが、朝鮮における影響力が弱いために補給は危ぶまれる状況であった。ロシアは日本に軍量で大きく勝る中、補給線の圧迫のため遼東半島の陸側を遮断し、日本の旅順防衛隊は孤立した。
1904年冬には枯渇した補給から日本軍の士気は大きく低下、まもなく旅順が陥落し、ロシア優位の講和条約であるポーツマス条約が締結され、ロシア帝国の韓国における優越権の明文化、その他日露の係争地のロシアへの譲渡、遼東半島一部の返還という名目のロシアによる占領が始まった。
