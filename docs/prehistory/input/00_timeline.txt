# 独露同盟の成立

1890年、ドイツ帝国で社会主義者鎮圧法の延長が可決され、宰相オットー・フォン・ビスマルクの失脚は回避された。ビスマルクは追放条項で妥協し、保守派・国民自由党右派・中央党の一部の支持を得た。これにより、皇帝ヴィルヘルム2世との対立は決定的なものとならず、彼の外交方針は維持された。

ビスマルクはフランス孤立化のため、ロシア帝国との協調を重視した。その結果、独露再保障条約は延長され、ロシアの対仏接近は阻止された。以後、独露関係は経済協力、バルカン調整、反革命協力を含む保守帝国同士の協商へ発展し、1910年代には正式な独露同盟となった。

# 世界大戦の勃発

独露協調の強化により、オーストリア＝ハンガリー帝国はドイツへの不信を強め、ロシアに対抗するためイギリス・フランス側へ接近した。オスマン帝国も黒海・海峡・カフカス方面でのロシアの圧力を恐れ、協商陣営に加わった。一方、イタリア王国はオーストリアとの領土問題から独露同盟側に参加した。

1914年、バルカン危機、英独海軍対立、仏独対立、露墺対立が重なり、世界大戦が勃発した。東部戦線ではロシア軍がオーストリア＝ハンガリーを圧迫し、同帝国は民族問題の激化により崩壊へ向かった。オスマン帝国もカフカス、メソポタミア、黒海方面で敗北を重ねた。西部戦線ではドイツ軍が塹壕戦を突破し、フランス本土へ侵攻した。

# フランス革命と講和

1917年秋、フランスでは敗戦の危機、軍の士気低下、都市部のストライキが重なり、第三共和政の権威が崩壊した。パリで蜂起が発生し、急進社会主義者、労働組合、反戦派兵士が臨時革命委員会を組織したことで、フランス・コミューンが成立した。

新政府は戦争継続能力を失い、1918年にドイツ・ロシアと講和した。フランスは東部国境の非武装化、賠償、ベルギー方面からの撤退、北アフリカ・中東権益の整理を受け入れた。大陸の主要同盟国を失ったイギリスも講和に追い込まれ、独露同盟は決定的勝利を収めた。

# 戦後秩序

戦勝により、ドイツでは皇帝制と軍部の威信が高まった。しかし、社会民主党、中央党、進歩人民党は戦時協力の代償として議会改革を要求した。フランス革命への警戒もあり、1918年末には限定的な憲法改革が行われた。宰相は皇帝が任命し続けたが、帝国議会多数派との協調が求められ、宣戦・講和・重要同盟には議会と連邦参議院の承認が必要となった。こうしてドイツ帝国は、皇帝制を維持した半議会制的立憲君主国へ変化した。

オーストリア＝ハンガリーは解体され、旧領には複数の民族国家が成立した。オスマン帝国も解体され、海峡、アルメニア、メソポタミア、シリアをめぐって独露の影響力が拡大した。

# イタリアと西欧革命圏

イタリアは戦勝国としてトレンティーノ、イストリア、ダルマチア沿岸の一部、アルバニアへの影響権、リビア支配の承認を得た。しかし講和秩序の主導権はドイツとロシアが握り、国内には不満が残った。フランス革命への恐怖から、イタリアは革命化せず、反革命的な国家主義王国へ傾いた。

一方、スペインでは王政不信、労働運動、モロッコ戦争の失敗が重なり、1920年代前半に第二共和政が前倒しで成立した。スペイン共和国はフランス・コミューンと協調し、フランスとともにインターナショナルを形成した。

# 英米と世界恐慌

イギリスは講和により帝国の威信を失ったが、セイロン、モルディブ、シンガポール、アデンなどの海上拠点を維持し、海洋帝国の再建を図った。

1929年、アメリカ発の株価暴落とドイツの過剰な軍事・植民地支出が重なり、世界恐慌が発生した。アメリカではニューディール政策が十分な成果を上げられず、1936年大統領選挙で共和党のフランク・ノックスが勝利した。ノックス政権は英米協調と海洋通商秩序の再建を掲げ、独露大陸同盟に対抗した。

# 1930年代の国際構造

1930年代後半、世界は三つの陣営に再編された。ドイツ、ロシア、イタリアは大陸秩序の維持を目指し、フランスとスペインはインターナショナルとして革命輸出を掲げた。イギリスとアメリカは海洋通商秩序の再建を目的に接近した。

英米とインターナショナルは思想的には対立していたが、独露による大陸覇権を阻止する点で利害が一致した。こうして世界は、インターナショナルおよび英米海洋陣営と、独露大陸同盟の対立を軸に、次なる大戦へ向かっていった。
