# 世界大戦の勃発

## 概要

独露協調の強化を受け、オーストリア＝ハンガリー（AUS）とオスマン帝国（TUR）は英仏側の協商陣営へ、イタリア王国（ITA）はオーストリアとの領土問題から独露同盟側へ加わった。1914年、バルカン危機・英独海軍対立・仏独対立・露墺対立が重なって世界大戦が勃発し、ヨーロッパは独露伊陣営と英仏墺土陣営の全面戦争へ突入した。東部戦線ではロシア（RUS）が墺洪とオスマンを圧迫し、西部戦線ではドイツ（GER）がフランス（FRA）本土へ侵攻した。

## 経緯

独露協調の強化により、オーストリア＝ハンガリー帝国はドイツへの不信を強め、ロシアに対抗するためイギリス・フランス側へ接近した。オスマン帝国も黒海・海峡・カフカス方面でのロシアの圧力を恐れ、協商陣営に加わった<!-- TODO: TUR が協商（英仏）側に立つ経緯は原文では上記のみ。史実ではドイツ側であり、本作での立場確定の根拠は TUR 前史ファイルで要補完 -->。一方、イタリア王国はオーストリアとの領土問題から独露同盟側に参加した<!-- TODO: ITA が独露陣営に加わる詳細な経緯は原文に乏しい。ITA 前史ファイルで要確認・補完 -->。

1914年、バルカン危機、英独海軍対立、仏独対立、露墺対立が重なり、世界大戦が勃発した<!-- TODO: GER 原文には開戦の正確な月日が無く年のみ。日本側原文は史実通り 1914.7.28 を記す。開戦日の確定は要判断 -->。前段の[ツァーベルン事件と開戦前夜](1913_zabern-affair.md)で示されたとおり、ヨーロッパは独露伊陣営と英仏墺土陣営の全面戦争へ突入した。

東部戦線ではロシア軍がオーストリア＝ハンガリーを圧迫し、同帝国は民族問題の激化により崩壊へ向かった<!-- TODO: 墺洪の崩壊・解体の正確な年が原文に未記載 -->。オスマン帝国もカフカス、メソポタミア、黒海方面で敗北を重ねた。西部戦線ではドイツ軍が塹壕戦を突破し、フランス本土へ侵攻した。

バルカン半島では、1915年にブルガリア（BUL）が、ロシアの後援するセルビアからマケドニアを奪回するため英仏墺土側で参戦し、セルビア領マケドニアを占領した。ギリシャ（GRE）では親独露中立を採る国王派が親英仏派との「国民分裂」を制し、ブルガリア参戦後に対ブルガリアへ限定して独露側で参戦した。ルーマニア（ROM）は中立を保ったが、フランス革命で大勢が決した1917年末、ロシアの誘いを受けて対墺宣戦し、トランシルヴァニアへ進駐した。これらの参戦の清算は[戦後秩序（墺洪・オスマンの解体）](1918_post-war-order.md)で確定する。

日本（JAP）は同盟関係にあったイギリスを支持して参戦したが、独露同盟に対抗する構図の中で極東防衛を主軸とする限定的な軍事行動にとどまった。1917年から1918年にかけて英仏が敗北したことにより日本の国際的地位は相対的に低下し、これに伴う[戦争責任問題から原政権は退陣する](1918_hara-cabinet-fall.md)ことになる。
