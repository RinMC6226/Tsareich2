# 高橋是清の積極財政と経済回復

## 概要

1933年頃、高橋是清が再び政権中枢に復帰し、金輸出再禁止による事実上の金本位制離脱と公債発行を伴う積極財政政策を実施した。農村救済費の拡充や公共事業の拡大を通じて有効需要の創出を図った結果、1934年頃までに国内経済（JAP）は回復基調へと転じた。

## 経緯

1928年に成立した浜口雄幸内閣は財政規律を重視した緊縮政策を推進したが、1927年の金融不安および1929年に顕在化した世界的経済危機の影響により国内経済は急速に悪化した。1931年には同内閣が退陣して若槻禮次郎内閣が成立したものの、輸出の急減と金融不安の深刻化に直面した結果、経済政策の転換が不可避となった。

これを受けて1933年頃には高橋是清が再び政権中枢に復帰し、次の積極財政政策を実施した。

- 金輸出再禁止による、事実上の金本位制離脱。
- 公債発行を伴う積極財政の展開。
- 農村救済費の拡充。
- 公共事業の拡大。

これらを通じて有効需要の創出を図った結果、1934年頃までに国内経済は回復基調へと転じた。
