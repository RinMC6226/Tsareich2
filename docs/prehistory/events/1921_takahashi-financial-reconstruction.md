# 高橋是清の財政再建と協調外交路線の確立

## 概要

1921年以降、高橋是清が政権中枢を担い、第一次世界大戦の戦費による財政悪化の是正と外債整理を中心とする経済再建政策を推進した。1924年以降には加藤高明が内閣を率いてドイツ帝国およびロシア帝国との関係再構築を進め、対外的に非拡張的かつ協調的な外交路線が確立された。

## 経緯

[戦争責任問題による原政権の退陣](1918_hara-cabinet-fall.md)を受けて、大日本帝国（JAP）では政権の立て直しが課題となった。1921年以降、高橋是清が政権中枢を担い、戦費による財政悪化の是正と外債整理を中心とする経済再建政策を推進した。

## 帰結 / ゲームへの反映

- 戦費による財政悪化を是正し外債整理を進めた経済再建は、1936年時点で日本が財政的に安定した中堅的立憲国家として描かれる根拠。
- 加藤高明内閣によるドイツ帝国・ロシア帝国との関係再構築は、1936年初期外交の非拡張的・協調的な路線の起点。両国に対する協調姿勢の初期 opinion / 外交関係の根拠。
- ここで確立された協調外交路線は、その後の[緊縮政策と昭和恐慌](1928_showa-depression.md)を経ても基調として維持され、軍部の政治的発言力が低位に抑制されたまま議会主導の政策決定体制が続く前提となる。
