# 海軍競争と第二次モロッコ事件

## 概要

1911年、ドイツ（GER）の砲艦派遣とフランス（FRA）のモロッコ内政介入をめぐり、第二次モロッコ事件として緊張が再燃した。外務長官アルフレート・フォン・キーデルレン＝ヴェヒターは、ロシア（RUS）との協調を損なわぬ範囲でフランスに圧力を加えて交渉し、アフリカで一定の補償を得た。しかし英独（ENG–GER）海軍対立はさらに深まり、ティルピッツら海軍派の拡張論を強め、独露同盟は大陸安全保障を越えて英国海洋覇権への対抗軸としても機能するようになった。

## 経緯

1911年の第二次モロッコ事件では、ドイツ海軍の砲艦派遣とフランスのモロッコ内政介入をめぐり再び緊張が高まった。外務長官アルフレート・フォン・キーデルレン＝ヴェヒターは、フランスに圧力を加えつつも、ロシアとの協調を損なわない範囲で交渉を進めた。

ドイツはアフリカで一定の補償を得たが、英独海軍対立はさらに深まった。ティルピッツら海軍派は、英仏協商がドイツの通商と植民地政策を封じ込めようとしていると主張し、海軍拡張論を強めた。

これにより、独露同盟は大陸安全保障の枠を越え、英国海洋覇権への対抗軸としても機能するようになった。
