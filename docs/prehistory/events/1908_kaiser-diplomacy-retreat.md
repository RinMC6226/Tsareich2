# 皇帝外交の後退（デイリー・テレグラフ事件）

## 概要

1908年10月、デイリー・テレグラフ事件が発生した。英独関係の改善を意図したヴィルヘルム2世（GER）の発言は、かえってイギリス（ENG）世論の不信を深め、ドイツ国内でも皇帝の個人的外交への批判を招いた。結果として独露協調は、皇帝個人の判断から宰相府・外務省・参謀本部が管理する制度的な国家政策へと移行した。

ヴィルヘルム2世は英独関係の改善を意図して発言したが、記事はイギリス世論の不信を深め、ドイツ国内でも皇帝の個人的外交への批判を招いた。帝国議会では中央党、社会民主党、進歩派が、外交政策における宰相と外務省の責任明確化を求めた。

この事件によりヴィルヘルム2世の威信は傷ついたが、同時に独露協調は皇帝個人の判断ではなく、宰相府・外務省・参謀本部によって管理される国家政策へ移行した。これにより、独露同盟はより制度的な外交路線として維持されることになった。
