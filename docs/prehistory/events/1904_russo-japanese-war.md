# 日露戦争

## 概要

1904年、ロシア帝国（RUS）と大日本帝国（JAP）が満州・朝鮮の権益をめぐって開戦した。日本は朝鮮での影響力が弱く補給が危ぶまれる状況にあり、軍量で勝るロシアが遼東半島の陸側を遮断して旅順防衛隊を孤立させた。1904年冬に補給枯渇で日本軍の士気が低下して旅順が陥落し、ロシア優位の講和条約「ポーツマス条約」が締結された。

## 経緯

開戦に至る前段については[日露戦争開戦前夜](1903_russo-japanese-war-eve.md)を参照。

旅順は日本によってある程度要塞化されていたが、朝鮮における影響力が弱いために補給は危ぶまれる状況であった。ロシアは日本に軍量で大きく勝る中、補給線の圧迫のため遼東半島の陸側を遮断し、日本の旅順防衛隊は孤立した。

1904年冬には枯渇した補給から日本軍の士気は大きく低下し、まもなく旅順が陥落した。これによりロシア優位の講和条約であるポーツマス条約が締結され、以下が定められた。

- ロシア帝国の韓国における優越権の明文化。
- その他、日露の係争地のロシアへの譲渡。
- 遼東半島一部の「返還」という名目による、ロシアによる占領の開始。
