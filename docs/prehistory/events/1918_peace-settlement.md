# 1918年講和と独露同盟の勝利

## 概要

1917年秋のフランス革命でフランス・コミューンが成立した結果、新政府は戦争継続能力を失い、1918年にドイツ・ロシアと講和した。フランスは東部国境の非武装化・賠償・ベルギー方面からの撤退・北アフリカ／中東権益の整理を受け入れ、大陸の主要同盟国を失ったイギリスも講和に追い込まれた。これにより独露同盟は決定的勝利を収めた。

## 経緯

世界大戦の西部戦線でドイツ軍が塹壕戦を突破しフランス本土へ侵攻するなか、1917年秋にフランスでは敗戦の危機・軍の士気低下・都市部のストライキが重なって第三共和政の権威が崩壊し、パリの蜂起を経て[フランス・コミューン](1917_french-revolution.md)が成立した。

革命によって成立したコミューン新政府は、もはや戦争を継続する能力を持たなかった。新政府は1918年にドイツ・ロシアと講和し、以下を受け入れた。

- 東部国境の非武装化
- 賠償
- ベルギー方面からの撤退
- 北アフリカ・中東権益の整理

大陸の主要同盟国であったフランスを失ったことで、イギリスも単独での戦争継続が困難となり、講和に追い込まれた。こうして独露同盟は世界大戦に決定的勝利を収めた。

## 帰結 / ゲームへの反映

- この勝利が、1936年における独露大陸同盟の覇権的地位の起点となる。戦勝でドイツの皇帝制と軍部の威信が高まり、[ドイツ帝国の憲法改革（半議会制立憲君主国へ）](1918_german-constitutional-reform.md)へつながる。
