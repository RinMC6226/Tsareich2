# 1918年講和（ベルリン条約）と独露同盟の勝利

## 概要

1917年秋のフランス革命でフランス・コミューンが成立した結果、新政府は戦争継続能力を失った。1918年、戦勝国はベルリンに講和会議を召集し、敗戦各国の処理を一括する単一講和条約「ベルリン条約」を締結した。フランスは領土割譲・北部非武装地帯（DMZ）・軍備制限・艦隊処分・賠償・戦争責任条項を受け入れ、大陸の主要同盟国を失ったイギリスも講和に追い込まれた。これにより独露同盟は世界大戦に決定的勝利を収めた。

## 経緯

### 講和会議とベルリン条約

世界大戦の西部戦線でドイツ軍が塹壕戦を突破しフランス本土へ侵攻するなか、1917年秋にパリの蜂起を経て[フランス・コミューン](1917_french-revolution.md)が成立した。革命によって成立したコミューン新政府は、もはや戦争を継続する能力を持たなかった。

1918年、戦勝国は主催国ドイツの首都ベルリンに講和会議を召集した。敗戦各国・解体帝国の処理は国別の条約群に分けられず、単一の条約に一括された。会議の主導権は独露の二巨頭が握り、議事の実態は両国間の利害調整——バルカン・海峡・中東・植民地の配分——であった。戦勝国でありながら[イタリア](1918_italy-postwar-nationalist-turn.md)は会議の周縁に置かれ、「不満足な勝者」となる素地が作られた。

### 対フランス条項

- **領土割譲**: アルザス＝ロレーヌをドイツへ、ノール／パ・ド・カレーをベルギーへ、コルシカ島をイタリアへ割譲。<!-- TODO: ベルギーが受領した根拠（大戦中の立場）は未確定 -->
- **北部・東部国境の非武装化（DMZ）**: 首都パリを含む北部5地域（イル・ド・フランス、ピカルディ、シャンパーニュ、西ノルマンディー、アルザス＝ロレーヌ仏領側）を非武装地帯とし、当初はドイツ軍が駐留した。条約違反は「署名国全体に対する敵対行為とみなす」と宣言されたが、自動的な制裁手続きは定められなかった。
- **軍備制限**: 陸軍の上限15万、徴兵制の禁止、戦車・軍用機・潜水艦の保有禁止、参謀本部の解体。
- **艦隊処分**: 仏艦隊の引き渡しが要求されたが、艦隊将兵はこれを拒否してトゥーロン軍港で自沈した。
- **賠償**: 莫大な賠償金が課された。支払いは金および現物（鉄・ボーキサイト）。
- **戦争責任条項**: 開戦の責任をフランスとその同盟国に帰す条項が明記された。
- **植民地・権益の処分**: チュニジアはイタリアの保護下へ。モロッコは1906年議定書体制（[第一次モロッコ事件](1905_first-moroccan-crisis-tangier.md)）の延長線上で仏の監督権が剥奪され独立へ。シリア・レバノン・パレスチナ方面はドイツの勢力圏へ。インドシナはドイツ領（独領東アジア）へ。西アフリカ（AOC）とアルジェリア（ALG）はフランスが従属領として保持した。<!-- TODO: AOC・ALG が残された理由は保留中 -->

### 対イギリス講和

大陸の主要同盟国であったフランスを失ったことで、イギリスも単独での戦争継続が困難となり、講和に追い込まれた。イギリスは中東・地中海の権益（キプロス、エジプト、メソポタミア・シリア方面）を失った。<!-- TODO: 対英条項の具体（講和に至る経緯・喪失の明細・海軍制限の有無）は未討議。確定後に追記 -->

### 墺洪・オスマンの解体

単一条約であるベルリン条約は、敗戦側帝国オーストリア＝ハンガリーとオスマン帝国の解体処分も同時に定めた。詳細は[戦後秩序（墺洪・オスマンの解体）](1918_post-war-order.md)を参照。

## 帰結 / ゲームへの反映

- この勝利が、1936年における独露大陸同盟の覇権的地位の起点となる。戦勝でドイツの皇帝制と軍部の威信が高まり、[ドイツ帝国の憲法改革（半議会制立憲君主国へ）](1918_german-constitutional-reform.md)へつながる（条約調印は改革「前」の旧体制下で行われた時系列となる点に注意）。
- 対仏条項は FRA の1936年初期状態の直接の根拠となる: DMZ 5州（state 16・785・18・1065・17）、割譲3州（state 28・29・1）、従属国 AOC・ALG。軍備制限（徴兵禁止・戦車禁止）は「秘密再軍備」（国家労働奉仕団・偽装戦車工場）の前提、トゥーロン自沈はダルランの「地中海艦隊再建」の前提、調印の屈辱と戦争責任条項は復讐主義（レヴァンシズム）の物語的核となる。
- 賠償と DMZ のその後: 1920年代は支払い継続（1927年の財産没収が原資）→ 1929年世界恐慌 → 1930年頃、賠償減額と引き換えにドイツ軍が DMZ から撤兵（以後は査察委員会のみ）→ 支払い猶予 → 1933〜34年にデア政権が支払いを公式破棄 → 1936年時点では不払い・査察体制のみが残る。これが1936年の「DMZ進駐」イベント（史実ラインラント進駐相当）の与件となる。なお独は取り立てのための担保占領（史実ルール占領相当）を行わない——1930年まで DMZ 駐留という常設の担保を持ち、戦勝国として財政的切迫もないため。
- 大陸同盟国を失って講和したイギリス（ENG）は帝国の威信を喪失する。これは英米海洋陣営再建の出発点であり、1936年の三陣営構造の前提となる。<!-- TODO: 対英条項の確定後に具体化 -->
- この講和は[戦後秩序（墺洪・オスマンの解体）](1918_post-war-order.md)と一体で、独露の大陸覇権という1936年初期状態を形づくる。
