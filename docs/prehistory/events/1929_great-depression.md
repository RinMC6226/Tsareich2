# 世界恐慌の発生

## 概要

1929年、アメリカ発の株価暴落とドイツの過剰な軍事・植民地支出が重なり、世界恐慌が発生した。アメリカ合衆国（USA）ではニューディール政策が十分な成果を上げられなかった。世界経済の動揺は英米（ENG）と独露大陸同盟の双方に影を落とし、1930年代の国際構造再編の背景となった。

## 経緯

イギリス（ENG）は世界大戦の講和により帝国の威信を失ったが、セイロン、モルディブ、シンガポール、アデンなどの海上拠点を維持し、海洋帝国の再建を図っていた。

## 帰結 / ゲームへの反映

- アメリカ発の株価暴落＋ドイツの過剰な軍事・植民地支出という二重の要因で恐慌が発生 → 1936年初期における独露大陸同盟側の経済的負荷・米国の不安定の根拠。
- USA のニューディール政策が不発に終わった → 1936年初期のアメリカの経済停滞・現政権への不満の根拠（後の1936年大統領選でのノックス勝利へつながる）。
- ENG は帝国の威信を失いつつも海上拠点（セイロン、モルディブ、シンガポール、アデン等）を保持し海洋帝国再建を志向 → 1936年初期の英国の勢力圏・海洋戦略の根拠。
