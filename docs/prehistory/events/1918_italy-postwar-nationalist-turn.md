# イタリアの戦後処理と国家主義王国化

## 概要

戦勝国イタリア王国（ITA）は、トレンティーノ、イストリア、ダルマチア沿岸の一部、アルバニアへの影響権、リビア支配の承認を得た。だが講和秩序の主導権はドイツとロシアが握り、国内には不満が残った。フランス革命への恐怖から、イタリアは革命化せず、反革命的な国家主義王国へ傾いた。

## 経緯

イタリア王国はオーストリアとの領土問題から独露同盟側に立って参戦し、世界大戦を戦勝国として終えた。戦後処理において、イタリアはトレンティーノ、イストリア、ダルマチア沿岸の一部、アルバニアへの影響権、リビア支配の承認といった領土・勢力圏の利得を獲得した。

しかし、講和秩序そのものの主導権はドイツとロシアが握っており、勝者でありながら大陸秩序の中心に座ることはできなかった。このため、戦勝の成果と引き換えに国内には不満が残った。

同時期、隣接する西欧ではフランス・コミューンが成立しており、イタリアもまた革命の波及を恐れる立場にあった。このフランス革命への恐怖が国内の方向性を決定づけ、イタリアは革命化を回避し、反革命的な国家主義王国へと傾いていった。

## 帰結 / ゲームへの反映

- ITA は戦勝国でありながら独露主導の講和秩序に不満を抱える「不満足な勝者」として始まる → 初期の対独露関係・国内世論の根拠。
- 反革命・国家主義的な王国という性格づけ → 1936年初期の政体（権威主義／国家主義系）とイデオロギー傾向の根拠。
- 獲得した勢力圏（トレンティーノ、イストリア、ダルマチア沿岸の一部、アルバニアへの影響権、リビア）→ 初期の州保有・属国／勢力圏関係の根拠。
- フランス・コミューンへの恐怖が反革命姿勢の動因 → 対インターナショナル（FRA/SPR）関係の根拠。
