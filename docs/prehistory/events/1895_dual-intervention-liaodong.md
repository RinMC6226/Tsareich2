# 独露干渉と日本海危機

## 概要

1895年、下関条約で日本が遼東半島を確保した動きに警戒したロシア帝国（RUS）は列強に干渉協力を打診したが、イギリス（ENG）は不干渉、フランス（FRA）は無関心の姿勢を取り、結果として独露二国（GER・RUS）が日本（JAP）へ「差し迫った懸念」を通告した。日本陸軍が強く反発して返還拒否と軍事的現状維持を通達し、翌1896年にはロシア極東艦隊による威圧航行で「日本海危機(1896)」が発生したが、武力衝突には至らず地域の軍事的緊張が高まった。

## 経緯

1895年、日本は下関条約によって遼東半島を確保したが、この動きに事前に警戒感を示していたロシア帝国（RUS）政府は、列強諸国に干渉協力の意思を問うた。しかしイギリス（ENG）は不干渉を示し、フランス（FRA）は特段の興味がないとしたため、独露二国（GER・RUS）での実行となった。

独露二国から日本（JAP）に示された「差し迫った懸念」に対し、日本では陸軍高官が強く反発した。二度の交渉の末、日本はロシア・ドイツに対して遼東半島返還の拒否と軍事的現状維持を通達した。

1896年、日本は遼東半島支配の正当化のため現地の整備に力を入れた。これに対しロシアは早期の軍事的強硬策を考慮したが、シベリア鉄道未成ゆえに陸軍力の行使は不可能と判断し、ドイツもこの判断に追従した。<!-- TODO: 「シベリア鉄道未成により陸軍力行使不可、独もこれに追従」という前提を確認する。 -->

しかしロシア極東艦隊は装甲巡洋艦ルーリクを含む5隻で威圧航行を行い、日本側の巡洋艦や哨戒艦複数とにらみ合う「日本海危機(1896)」が発生した。直接の武力衝突は発生しなかったが、地域の軍事的緊張は極めて高い状態となった。また、日本は遼東半島の防衛に国力を大きく割いたため、朝鮮進出が遅れることとなった。
