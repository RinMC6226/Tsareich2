# 1936年米大統領選とノックス政権

## 概要

[世界恐慌](1929_great-depression.md)後、アメリカ合衆国（USA）ではニューディール政策が十分な成果を上げられなかった。1936年の大統領選挙で共和党のフランク・ノックスが勝利し、ノックス政権は英米協調と海洋通商秩序の再建を掲げて、独露大陸同盟に対抗する姿勢をとった。

## 経緯

1929年のアメリカ発の株価暴落に端を発する世界恐慌に対し、アメリカではニューディール政策が実施されたが、十分な成果を上げることができなかった。

1936年の大統領選挙で共和党のフランク・ノックスが勝利した。ノックス政権は次の方針を掲げた。

- 英米協調の推進。
- 海洋通商秩序の再建。
- 独露大陸同盟への対抗。

## 帰結 / ゲームへの反映

- ノックス政権の成立により、アメリカ（USA）はイギリス（ENG）と接近し、海洋通商秩序の再建を軸に独露大陸同盟へ対抗 → [1930年代の三陣営への再編](1930s_three-bloc-order.md)における英米海洋陣営形成の中核。
- 1936年初期の米国の対外姿勢（反独露・親英・海洋通商重視）の根拠。
