# ドイツ帝国の憲法改革（半議会制立憲君主国へ）

## 概要

戦勝によりドイツ（GER）では皇帝制と軍部の威信が高まったが、社会民主党・中央党・進歩人民党は戦時協力の代償として議会改革を要求した。フランス革命への警戒もあり、1918年末に限定的な憲法改革が行われ、宣戦・講和・重要同盟には帝国議会と連邦参議院の承認が必要となった。これによりドイツは皇帝制を維持したまま、半議会制的立憲君主国へと変化した。

## 経緯

世界大戦の勝利は、ドイツ帝国における皇帝制と軍部の威信を一段と高めた。しかしその一方で、戦時に挙国一致体制を支えた社会民主党・中央党・進歩人民党は、戦時協力の代償として議会改革を要求した。

加えて、隣国フランスで第三共和政が崩壊し急進的な革命政権（フランス・コミューン）が成立したことへの警戒が、体制内改革を後押しした。革命を未然に防ぐため、支配層は一定の譲歩を選んだのである。

こうして1918年末、限定的な憲法改革が実施された。<!-- TODO: 改革の正確な月日が原文に無い（「1918年末」とのみ）。 --> 宰相は引き続き皇帝が任命したが、帝国議会多数派との協調が求められるようになり、宣戦・講和・重要同盟の締結には帝国議会と連邦参議院の承認が必要となった。これによりドイツ帝国は、皇帝制を維持しつつも議会の関与を制度化した半議会制的立憲君主国へと変化した。

この改革は、同時期の[1918年講和と独露同盟の勝利](1918_peace-settlement.md)という戦勝の文脈、および[戦後秩序（墺洪・オスマンの解体）](1918_post-war-order.md)による大陸での独露優位を前提とする。
