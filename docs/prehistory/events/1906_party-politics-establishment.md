# 政党政治の定着と軍部影響力の後退

## 概要

日露戦争の事実上の敗戦による政治的・社会的動揺を受け、伊藤博文の主導で暫定的な政権再編が行われたのち、1906年1月に西園寺公望を首班とする内閣が成立した。1906年から1910年頃にかけて軍部の政治的影響力が後退する一方で議会政治が急速に定着し、1910年前後には原敬を中心とする政党内閣が確立された。

## 経緯

大日本帝国（JAP）は、[日露戦争](1904_russo-japanese-war.md)において当初優勢に戦局を進めたものの、戦費の増大と兵站の限界により決定的勝利を得ることができず、1905年9月5日に締結されたポーツマス条約によって有利な条件を獲得できなかった。これは事実上の敗戦として国内に深刻な政治的・社会的動揺を引き起こし、同年中に大規模な民衆騒擾が発生するとともに桂太郎内閣が総辞職した。

これを受けて伊藤博文の主導により暫定的な政権再編が行われたのち、1906年1月には西園寺公望を首班とする内閣が成立した。以後1906年から1910年頃にかけて軍部の政治的影響力が後退する一方で、議会政治が急速に定着した。

## 帰結 / ゲームへの反映

- 1936年初期において JAP の軍部の政治的発言力が低位に抑制されている根拠（国民精神「軍部の弱体化」）。
- 議会主導の政策決定体制・立憲国家路線の起点。1936年の「憲政の常道」「大正デモクラシー」といった国民精神へ連なる土台。
- 西園寺公望・原敬ら政党政治家の台頭は、後年の協調的・非拡張的な外交路線の前提となる。
