# 緊縮政策と昭和恐慌

## 概要

1928年に成立した浜口雄幸内閣は財政規律を重視した緊縮政策を推進したが、1927年の金融不安および1929年に顕在化した世界的経済危機の影響により国内経済は急速に悪化した。1931年には同内閣が退陣して若槻禮次郎内閣が成立したものの、輸出の急減と金融不安の深刻化に直面し、経済政策の転換が不可避となった。

## 経緯

大日本帝国（JAP）では、1928年に浜口雄幸内閣が成立し、財政規律を重視した緊縮政策を推進した。

しかし、1927年の金融不安、および1929年に顕在化した世界的経済危機の影響により、国内経済は急速に悪化した。

1931年には浜口内閣が退陣して若槻禮次郎内閣が成立したものの、輸出の急減と金融不安の深刻化に直面した結果、経済政策の転換が不可避となった。

## 帰結 / ゲームへの反映

- 緊縮政策と世界恐慌の重なりによる国内経済の急速な悪化は、1936年初期状態の国民精神「世界恐慌」の根拠となる経済的背景。
- 経済政策の転換が不可避となったことが、1933年頃の[高橋是清による積極財政と経済回復](1933_takahashi-reflation.md)への直接の前段となる。緊縮から積極財政への路線転換はこの恐慌を受けて始まる。
- 軍部の政治的発言力が低位に抑制されたまま議会主導で経済危機に対処した経過は、1936年時点で日本が拡張主義に依拠しない中堅的立憲国家として安定する前提の一部。
