# 日露戦争開戦前夜

## 概要

1903年、ドイツ鉄道事業からの大規模な資本投入によりシベリア鉄道が完全に開通し、ロシア帝国は極東方面での大規模な軍事作戦が可能となった。これを背景にアレクサンドル・ベゾブラーゾフら陸軍関係者が日本との開戦を強く要求し、日本の満州撤退・朝鮮影響力拡大中止要求をロシアが拒否、1904年に日本がロシアに対して国交断絶を通告し、日露戦争の開戦に至った。

この極東への軍事力展開能力を背景に、ロシア帝国内ではアレクサンドル・ベゾブラーゾフをはじめとする陸軍関係者が、日本（JAP）との開戦を強く要求した。

日本はロシアに対し、満州からの撤退と朝鮮への影響力拡大中止を強く要求したが、ロシアは拡大しつつある極東戦力を根拠にこれを拒否した。

1904年、日本はロシアに対して国交断絶を通告し、日露戦争が開戦した。
