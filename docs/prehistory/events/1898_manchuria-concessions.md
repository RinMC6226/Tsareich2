# 満州権益

## 概要

ドイツ・ロシアの二か国は共同して清に広範な権益を要求し、東清鉄道敷設権をはじめとする広範な満州権益をロシアが獲得した。日本はこれに強く反発し、満州方面へより多くの陸軍を配置した。

## 経緯

[独露干渉と日本海危機](1895_dual-intervention-liaodong.md)を経て極東での協調を強めたドイツ帝国（GER）とロシア帝国（RUS）の二か国は、共同して清に対し広範な権益を要求した。

この要求により、東清鉄道敷設権をはじめとする広範な満州権益をロシアが獲得することとなった。

日本（JAP）はこの独露による満州権益の獲得に対して強く反発し、満州方面へより多くの陸軍を配置した。

## 帰結 / ゲームへの反映

- ロシアが東清鉄道敷設権をはじめとする満州権益を獲得 → 1936年初期状態における RUS の満州・極東方面での強い影響力・権益基盤の根拠。
- 独露の協調による対清共同要求 → GER と RUS の極東における協調関係の継続の根拠。
- 日本が満州方面へ陸軍を増強 → 1936年初期状態における JAP の満州方面への陸軍配置・対露警戒の根拠。
