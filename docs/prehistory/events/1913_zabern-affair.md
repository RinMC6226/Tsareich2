# ツァーベルン事件

## 概要

1913年、アルザス＝ロレーヌのツァーベルンで軍人と市民の衝突が起き、ドイツ帝国（GER）の軍部と文民社会の対立が露わになった。帝国議会では軍の越権行為が激しく批判され、参謀本部は西部国境防衛を理由に軍権強化を主張したのに対し、中央党と社会民主党は文民権利の侵害を批判した。この対立は翌1914年の開戦時に「城内平和」で一時的に覆い隠されたが、戦時協力の代償としての議会改革要求は残り、後の1918年改革へつながっていった。
