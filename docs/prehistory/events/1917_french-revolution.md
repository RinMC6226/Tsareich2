# フランス革命とコミューン成立

## 概要

1917年秋、フランス（FRA）では敗戦の危機、軍の士気低下、都市部のストライキが重なり、第三共和政の権威が崩壊した。パリで蜂起が発生し、急進社会主義者・労働組合・反戦派兵士が臨時革命委員会を組織したことで、フランス・コミューンが成立した。これによりフランスは戦争継続能力を失い、翌1918年の講和へと向かった。

## 経緯

西部戦線でドイツ軍が塹壕戦を突破しフランス本土へ侵攻するなか、フランスでは敗戦の危機が現実のものとなった。前線では軍の士気が低下し、都市部ではストライキが相次いだ。これらが重なって第三共和政の権威は崩壊した。

1917年秋、パリで蜂起が発生した。急進社会主義者、労働組合、反戦派兵士が臨時革命委員会を組織し、フランス・コミューンが成立した。
