# 義和団の乱

## 概要

義和団の乱に際し、日本（JAP）は遼東半島防衛に軍力を割いていたため派兵が約3000人にとどまった一方、ロシア（RUS）は7000人規模の大規模派兵で極東での強い影響力を保とうとした。日露独英を主とする連合軍が義和団と戦闘し、北京議定書でロシア・ドイツ（GER）の中国権益が明文化された結果、これを警戒した日本とイギリス（ENG）が接近することとなった。

## 経緯

義和団の乱では、日本（JAP）が遼東半島防衛に軍力を大きく用いていたため、派兵は3000人程度にとどまった。これに対しロシア（RUS）は7000人規模の大規模な派兵を行い、極東での強い影響力を保とうとした。

戦闘は、日露独英を主とする連合軍と義和団との間で行われ、最終的に北京議定書が締結された。議定書においては、ロシアとドイツ（GER）の中国権益が明文化された。

この露独による中国権益の明文化を強く警戒した日本とイギリス（ENG）は、互いに接近することとなった。
