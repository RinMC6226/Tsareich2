# 幣原喜重郎内閣と協調外交による安定

## 概要

1934年以降、幣原喜重郎を中心とする内閣が成立し、ドイツ帝国（GER）およびロシア帝国（RUS）との通商関係の安定化と極東における勢力均衡の維持を図る協調外交を推進した。イギリス（ENG）との関係を従来の同盟依存から限定的協調関係へと再編し、国際的緊張の緩和に努めた。

## 経緯

[高橋財政による経済回復](1933_takahashi-reflation.md)を土台として、1934年以降は幣原喜重郎を中心とする内閣が対外政策の協調路線を展開した。

- ドイツ帝国・ロシア帝国との通商関係の安定化。
- 極東における勢力均衡の維持。
- イギリスとの関係を、従来の同盟依存から限定的協調関係へ再編。

経済政策と外交政策の連動的再構築により、日本は世界恐慌の影響を比較的早期に緩和した。軍部の政治的発言力が低位に抑制されたまま議会主導の政策決定体制が維持され、1936年時点では拡張主義に依拠しない中堅的立憲国家として国際秩序の中に安定した地位を占めるに至った。

## 帰結 / ゲームへの反映

- 1936年初期の大日本帝国（JAP）が独露大陸同盟とは一定の距離を保ちつつ通商面で協調する立ち位置 → 初期外交関係・陣営非加盟の根拠。
- 対英関係が「同盟依存」から「限定的協調」へ再編済み → 1936年初期の日英関係の根拠（国民精神「日英同盟」の現状）。
- 軍部低位・議会主導の維持 → 初期政体・派閥バランス、拡張主義抑制の根拠。
