# オーストリア＝ハンガリーの離反（ボスニア危機）

## 概要

1908年10月、オーストリア＝ハンガリー（AUS）がボスニア・ヘルツェゴヴィナ併合を発表し、バルカン情勢が急速に緊張した。ベルリン（GER）はビスマルク以来の対露協調を優先してウィーンへの全面支持を避け、ロシア（RUS）との協議を通じてオーストリアに妥協を求めた。これによりウィーンの対独不信が拡大し、オーストリアはロシアの南下を最大の脅威としてイギリス・フランスへの接近を強めていった。
