# 戦後秩序（墺洪・オスマンの解体）

## 概要

1918年の独露同盟側の勝利と[ベルリン条約](1918_peace-settlement.md)に伴い、戦時に協商陣営へ属したオーストリア＝ハンガリー（AUS）とオスマン帝国（TUR）はいずれも解体された。旧オーストリア＝ハンガリー領では、オーストリア本体のドイツへの編入、ユーゴスラビアの成立、ガリツィアのロシア編入などの再編が行われ、ハンガリーはドイツの意向により「大ハンガリー」として温存された。旧オスマン領では海峡が国際管理下に置かれ、アルメニア・メソポタミアでロシアが、シリア方面でドイツが影響力を確立した。

## 経緯

### オーストリア＝ハンガリーの解体

東部戦線でロシア軍の圧迫と民族問題の激化を受けて崩壊へ向かっていたオーストリア＝ハンガリー帝国は、1918年の講和をもって解体され、旧領は次のとおり再編された。

- **オーストリア本体（ウィーン・上オーストリア・ティロル）はドイツが併合した**。南ティロルもドイツ領となった。<!-- TODO: 南ティロルを伊が要求し独に却下された、という会議の演出を採用するか未確定 -->
- **ユーゴスラビアが成立した**。ロシアの後援するセルビアを中核に、旧墺洪領の南スラヴ地域（スロベニア・クロアチア・ボスニア・ヘルツェゴヴィナ・モンテネグロ・マケドニア等）を統合した。1908年のボスニア危機以来「セルビアと正教徒の保護」を掲げてきたロシアの汎スラヴ政策の結実である。
- **ガリツィア＝ロドメリアとブコヴィナはロシアが併合した**。
- **トランシルヴァニアの半分はルーマニアへ割譲された**（セーケイ地方・クリシャナはハンガリー側に残留）。
- **ベーメン・メーレンは「チェコ国」としてドイツの保護下に置かれた**。スロバキアを含まない形での分離である。<!-- TODO: 傀儡化の経緯の詳細が未確定 -->
- **ハンガリーは「大ハンガリー」として存続した**。スロバキア・カルパティア＝ルテニア・ブルゲンラント・ヴォイヴォディナ・バナトを保持する。これはドイツの明確な意向によるものである——目と鼻の先のバルカン半島を、ロシアの影響下にあるセルビア（ユーゴスラビア）とルーマニアにすべて委ねるわけにはいかず、ドイツは対露緩衝国としてハンガリーにある程度の力を残すことを選んだ。**独露の利害対立は、講和会議のこの瞬間に既に顕在化していた**。
- **イストリアとトレンティーノはイタリアへ割譲された**（[イタリアの戦後処理](1918_italy-postwar-nationalist-turn.md)参照）。

なお、ポーランドについては何も決定されなかった。ポーランドは開戦のはるか以前（1795年）から分割されて存在せず、同盟のまま勝利した独露が両国国境を動かす理由はなかった。戦前の国境がそのまま維持され、唯一の変化は上記の旧墺領ガリツィアのロシア編入である。

### バルカン参戦国の処遇

- **ルーマニア**は、1917年末の対墺参戦（[世界大戦の勃発](1914_great-war-outbreak.md)参照）の対価としてトランシルヴァニアの半分を得た。ロシアは全トランシルヴァニアの割譲を推したが、ドイツが「遅参の便乗者」への報酬としてはこれで十分とし、ハンガリー温存の論理で押し切った。血を流しながら半分しか得られなかったルーマニアの不満は、ロシアとハンガリーの双方に向かって残り続ける。
- **ブルガリア**は敗戦側として清算された。1915年の参戦以来占領していたセルビア領マケドニアを全て剥奪され、ユーゴスラビアへ引き渡したうえ、西トラキアをギリシャへ割譲した。マケドニア・トラキアへの請求権だけが国民的怨念として残り、ブルガリアは修正主義国家として戦後を出発する。
- **ギリシャ**は対ブルガリア限定参戦の戦利品として西トラキアを獲得し、さらに戦後、ロシアがイギリスから没収したキプロスを正教外交の一環として引き渡された。戦わずに多くを得たギリシャは、ロシアの被保護国として戦後秩序に組み込まれた。

### オスマン帝国の解体

同じく協商側で戦い、カフカス・メソポタミア・黒海方面で敗北を重ねていたオスマン帝国も解体された。

- **ボスフォラス・ダーダネルス両海峡は国際管理下に置かれ、海峡委員会が管理する**。<!-- TODO: 委員会の構成国・実権の所在が未討議。ロシアの宿願が「直轄」でなく「国際委員会」で妥協された経緯は、ハンガリー問題と並ぶ独露間の摩擦点として要設計 -->
- **アルメニア・クルディスタン・メソポタミア（イラク）はロシアの保護下**に置かれた。
- **シリア（レバノン・パレスチナ・ヨルダンを含む地中海東岸）はドイツの保護下**に置かれた。
- **エジプトは独立し**、キプロスは前述のとおりギリシャへ渡った。<!-- TODO: エジプト独立とスエズの帰属の経緯は対英条項と一括で確定する -->

## 帰結 / ゲームへの反映

- 旧墺洪領の再編は1936年初期マップの直接の根拠となる: AUS 消滅（独領 state 4・152・153・39）、YUG 13州、HUN の大ハンガリー（スロバキア 70・71・664、ルテニア 73、ブルゲンラント 975、ヴォイヴォディナ 45、バナト 82・764 等を保持）、ROM のトランシルヴァニア（76・84）、露領ガリツィア（88〜91）・ブコヴィナ（80）、独傀儡 CZE（9・75・72）、伊領イストリア（852）・トレンティーノ（850）。
- **ハンガリー緩衝国化に始まる独露のバルカン利害対立**は、1936年のバルカン戦争（`docs/plan/skelton_contents/balkan_war.md`）の根本原因である。独圏（ハンガリー・ブルガリア）対 露圏（ユーゴスラビア・ルーマニア・ギリシャ）という1936年の構図、ルーマニアの「全トランシルヴァニア回復」要求、ブルガリアの対マケドニア・トラキア修正主義、ギリシャとユーゴの連携は、すべてこの講和処分に由来する。
- 旧オスマン領の処分は1936年の中東の根拠となる: 海峡委員会 STC（4州）、露衛星の ARM・KUR・IRQ、独傀儡 SYR（554・677・553・454・455・1059）、独立エジプト（EGY 16州）、ギリシャ領キプロス（183）、アナトリア残部 TUR（15州）。
- ロシアの取り分への不満（海峡を直轄できなかった等）は、ハンガリー問題と並んで1936年以降の独露関係の亀裂の種として設計に使用できる。
