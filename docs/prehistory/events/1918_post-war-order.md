# 戦後秩序（墺洪・オスマンの解体）

## 概要

1918年の独露同盟側の勝利と講和に伴い、戦時に協商陣営へ属したオーストリア＝ハンガリー（AUS）とオスマン帝国（TUR）はいずれも解体された。旧オーストリア＝ハンガリー領には複数の民族国家が成立し、旧オスマン領では海峡・アルメニア・メソポタミア・シリアをめぐってドイツ（GER）とロシア（RUS）の影響力が拡大した。
