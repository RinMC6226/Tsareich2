# 独露協調の固定化（第一次モロッコ事件）

## 概要

1905年3月31日、皇帝ヴィルヘルム2世がタンジールを訪問し、モロッコのスルタンの独立と列強の経済的機会均等を支持して、フランスのモロッコ支配に挑戦した。史実と異なり、独露再保障条約の延長によってロシア帝国がドイツを支持したため会議の構図は一変し、1906年4月の議定書でドイツが外交的勝利を収めた。これにより独露協調が「フランス封じ込め」の国家方針として固定化される一方、英仏協商を反独政治連携へ発展させる契機ともなった。

## 経緯

1905年3月31日、皇帝ヴィルヘルム2世はタンジールを訪問し、モロッコのスルタンの独立と列強の経済的機会均等を支持した。これは、フランス外相テオフィル・デルカッセが進めていたモロッコ支配に対する挑戦であり、ドイツ帝国（GER）は国際会議による解決を要求した。

史実ではアルヘシラス会議でドイツは孤立したが、この世界では独露再保障条約の延長によってロシア帝国（RUS）がドイツを支持し、会議の構図は大きく変化した。
