# 帝国議会と国内対立（1912年選挙）

## 概要

1912年1月12日の帝国議会選挙で、社会民主党（SPD）が最大勢力となった。しかし宰相は帝国議会ではなく皇帝に責任を負う立憲構造のため、議会多数派が内閣を組織することはなかった。SPD内部では独露同盟をめぐり、これを二正面戦争回避の現実外交として黙認する穏健派と、ツァーリズムとの提携を反動的外交と批判するルクセンブルク・リープクネヒトら左派が対立した。

## 経緯

工業化の進展と都市労働者層の拡大は、社会民主党（SPD）の躍進をもたらした。1912年1月12日の帝国議会選挙において、SPDは帝国議会最大党となった。

しかし、ドイツ帝国の立憲構造において宰相は依然として帝国議会ではなく皇帝に責任を負っていたため、議会で多数を占めた勢力がそのまま内閣を組織することはなかった。選挙による社会民主主義の伸長と、議院内閣制の不在という制度上の隔たりが、国内対立の構図を形づくった。

SPD内部では、独露同盟をめぐる対立が生じた。労働組合系の穏健派は、独露協調を二正面戦争回避の現実外交として黙認した。一方、ローザ・ルクセンブルクやカール・リープクネヒトに近い左派は、ツァーリズム（ロシア帝政）との提携を反動的外交として批判した。

なお、1912年選挙でSPDが帝国議会最大党となった点は史実とも一致しており、この代替史世界においても社会民主主義の伸長は自然な展開である。
