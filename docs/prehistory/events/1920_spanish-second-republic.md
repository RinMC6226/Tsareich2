# スペイン第二共和政の前倒し成立とインターナショナル形成

## 概要

スペイン（SPR）では王政不信、労働運動、モロッコ戦争の失敗が重なり、1920年代前半に第二共和政が史実より前倒しで成立した。スペイン共和国はフランス・コミューン（FRA）と協調し、フランスとともにインターナショナルを形成した。これにより西欧には独露大陸同盟とは異なる革命圏の核が生まれた。

## 経緯

世界大戦後の西欧では、フランスでフランス・コミューンが成立し、革命の波が大陸の一角に定着していた。スペインでは、王政への不信、労働運動の高揚、そしてモロッコ戦争の失敗という複数の要因が重なり、王政の権威が崩壊した。
