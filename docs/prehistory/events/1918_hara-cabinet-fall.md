# 戦争責任問題と原政権の退陣

## 概要

第一次世界大戦において日本は同盟関係にあったイギリスを支持して参戦したが、極東防衛を主軸とする限定的な軍事行動にとどまった。1917年から1918年にかけて英仏が敗北したことで日本の国際的地位は相対的に低下し、これに伴う戦争責任問題から原敬政権は退陣した。

## 経緯

大日本帝国（JAP）は、1914年7月28日に勃発した[第一次世界大戦](1914_great-war-outbreak.md)に際して、同盟関係にあったイギリス（ENG）を支持して参戦した。しかしドイツ帝国（GER）とロシア帝国（RUS）の同盟に対抗する構図の中で、日本の参戦は極東防衛を主軸とする限定的な軍事行動にとどまった。

1917年から1918年にかけて英仏が敗北したことにより、日本の国際的地位は相対的に低下した。これに伴う戦争責任問題から、原敬政権は退陣した。

## 帰結 / ゲームへの反映

- 英仏陣営の敗北という大戦結果は、日本が拡張主義に依拠しない中堅的立憲国家として再出発する起点。1936年の非拡張的・協調的な外交路線の前提となる。
- 原政権退陣後、1921年以降の[高橋是清による財政再建と協調外交路線](1921_takahashi-financial-reconstruction.md)へと連なる。戦費による財政悪化の是正と外交再構築は、この退陣を受けて始まる。
- 日本の国際的地位の相対的低下は、1936年時点で日本がドイツ帝国・ロシア帝国に対して劣勢ながら協調を選ぶ動機づけの背景。
