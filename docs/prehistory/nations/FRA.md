# フランス・コミューン（FRA）

## 概要（1936時点）

マルセル・デア率いる「国民サンディカリスト」による一党独裁体制下の革命国家。体制のイデオロギーは労働者の解放というよりも、敗戦の屈辱を晴らす極端な復讐主義（レヴァンシズム）によって支えられている。最大の政治的・軍事的課題は、首都パリが未だドイツの監視下にある北部非武装地帯（DMZ）の解消と、水面下で進められている軍隊の再建である。対外的には独露伊大陸同盟の打倒を至上目的とし、インターナショナルの盟友スペインと共に反独包囲網の形成を狙い、時として英米海洋陣営との実利的な妥協すら辞さない危険な火薬庫となっている。

このMODにおけるフランスの立ち位置は、**史実におけるナチスドイツのポジション**に相当する——敗戦国・領土喪失・非武装地帯・復讐主義的急進政権という構図である。ただしイデオロギー的基盤は民族主義ではなく、階級闘争・反帝国主義・革命的愛国心を融合した**国民サンディカリスム**（国家の統制と階級闘争、復讐主義の融合）である。

## 前史（POD → 1936）

### 大戦前のフランス（1890年代〜1914年）

1890年のビスマルク続投による独露同盟の成立は、フランスを深刻な外交的孤立の恐怖に陥れた。対抗策としてフランスは、長年の宿敵であったイギリス、そしてバルカン半島でロシアと対立するオーストリア＝ハンガリー、オスマン帝国と急接近し「協商陣営」を形成した。国内の第三共和政下では、普仏戦争以来の対独復讐心がくすぶり続け、モロッコ事件等を通じてドイツとの対立は後戻りできない水準まで先鋭化した。

- 1894年：露仏同盟の希望が断たれたことを受け、英仏間で秘密協商に向けた協議が開始される。
- 1905年：[第一次モロッコ事件](../events/1905_first-moroccan-crisis-tangier.md)。ドイツの介入に対し、英仏墺土の協調枠組みが機能しドイツを退ける。
- 1911年：[第二次モロッコ事件](../events/1911_second-moroccan-crisis.md)（アガディール危機）。仏独間の緊張が極限に達し、国内で国粋主義と排外主義が高揚する。

### 世界大戦と敗北（1914〜1917）

[1914年](../events/1914_great-war-outbreak.md)、バルカン危機を皮切りに世界大戦が勃発。フランスは協商陣営として独露伊の大陸同盟と激突した。しかし西部戦線において、ドイツ軍の圧倒的な物量と浸透戦術の前にフランス軍の塹壕線は破られ、本土深くへの侵攻を許した。首都パリに敵軍が迫る中、莫大な犠牲と絶望的な戦況、深刻な物資不足は軍の士気を崩壊させ、銃後では反戦ストライキが蔓延し始めた。

- 1914年：世界大戦勃発。フランス軍はプラン17を発動するが、ドイツ軍の猛攻により多大な損害を出す。
- 1916年：大規模な防衛戦でフランス軍が敗退。戦線が内陸部へ後退する。
- 1917年春：大反攻作戦が完全に失敗。前線部隊で抗命・反乱事件が多発する。

### フランス革命とコミューン成立（1917年秋）

[1917年秋](../events/1917_french-revolution.md)、ドイツ軍がパリ近郊に迫る中、ついに第三共和政の権威は地に堕ちた。前線の反乱兵士と都市部の労働者が結びつき、パリで大規模な武装蜂起が発生。政府機能は瓦解し、急進社会主義者やサンディカリストからなる「臨時革命委員会」が首都を掌握した。彼らは「フランス・コミューン」の成立を宣言し、ブルジョワ政府に代わってプロレタリアートによる徹底抗戦を叫んだが、現実は戦争継続能力を完全に喪失していた。

- 1917年9月：パリでゼネスト決行。治安部隊が発砲を拒否し、労働者側に合流。
- 1917年10月：政府がボルドーへ逃亡し、首都の統治機能が崩壊。臨時革命委員会（議長：ジャン・ジョレス）がパリ市庁舎を占拠。
- 1917年11月：「フランス・コミューン」成立宣言。前線の兵士に戦闘停止と「将校の武装解除」を呼びかけ、軍の指揮系統が事実上消滅する。

### 講和と領土喪失（1918〜1920）

[1918年](../events/1918_peace-settlement.md)、コミューン新政府は独露伊と屈辱的な講和条約を締結せざるを得なかった。アルザス＝ロレーヌとノール県周辺、コルシカ島を割譲し、首都パリを含むフランス北部に広大な非武装地帯（DMZ）が設定された。植民地は西アフリカ（AOC）とアルジェリア（ALG）を辛うじて保持したものの、莫大な賠償金が課された。この「国家の解体」とも言える過酷な条件は、革命の理想を打ち砕き、フランス人民の心に強烈な復讐心（ルサンチマン）を植え付けた。

- 1918年：講和条約調印。北部・東部国境の非武装化、ベルギー方面からの撤退、賠償金支払いが確定。割譲地から数十万人規模の引揚者が流入し、後の復讐主義の社会的基盤となる。
- 1919年：講和の責任を問われ、ジャン・ジョレスら革命初期の穏健派指導者が失脚（後に粛清）。「ジョレスの署名」は急進派にとって裏切りの代名詞となる。
- 1920年：DMZの監視を名目にドイツ軍の干渉が常態化。フランス国内で「革命的祖国防衛」の機運が高まる。

### 革命の制度化（1920年代）

1920年代のフランスは、講和の責任と路線対立を巡る激しい内部闘争と粛清の時代であった。最終的に、階級闘争論に「狂信的な愛国心と対独復讐主義」を融合させた急進派（国民サンディカリスト）が実権を掌握した。彼らは秘密警察（革命保安局）と民兵を用いて国内の王党派・カトリック勢力・穏健社会主義者を徹底的に弾圧した。同時期に第二共和政が成立した[スペイン](../events/1920_spanish-second-republic.md)と協調し「インターナショナル」を結成することで、革命輸出の皮を被った反独包囲網の足場を固めた。

- 1922年：急進派が党内クーデター（いわゆる「第二のブリュメール」）を起こし、コミューン政府の実権を掌握。秘密警察「革命保安局」が設立され、恐怖政治が始まる。
- 1924年：スペイン共和国との間にインターナショナル結成条約を調印。表向きは「世界革命の総司令部」だが、実態は反独包囲網の外交装置である。
- 1927年：国内の旧体制派（カトリック教会・保守ブルジョワ）の財産を完全没収し、国家統制経済への移行を完了。没収資産は賠償金支払いと秘密再軍備の原資に充てられる。

### 復讐主義の台頭と再軍備（1930年代）

[1929年の世界恐慌](../events/1929_great-depression.md)に対し、フランスは徹底した計画経済とブロック経済（植民地AOC・ALGからの搾取を含む）で対抗し、体制の正当性を強化した。1930年代に入ると、マルセル・デアを筆頭とする「ネオ・ソシアリスト（新社会主義者）」が権力を完全掌握。失われた領土の奪還とパリDMZの解消を至上命題に掲げ、イデオロギー的に相容れない英米陣営とも戦術的に妥協する姿勢を見せ始めた。トラクター工場を偽装した戦車生産など、秘密裏の再軍備計画が本格化している。

- 1931年：国家労働奉仕団が創設され、若年層の軍事教練が非公然に開始される。
- 1933年：デアが綱領演説「秩序・権威・国民」を行い、階級闘争と国民的復権を統合する「ネオ・ソシアリスム」を体制の公式教義とする。
- 1934年：マルセル・デアが国家元首（コミューン最高指導者）に就任。権力集中が完了。
- 1935年：スペインとの合同軍事演習を実施。秘密裏に新型機甲戦術のテストを行う。

[1930年代後半](../events/1930s_three-bloc-order.md)、世界は三陣営に再編された。フランスはスペインとともにインターナショナルとして革命輸出を掲げつつ、その真の目的は失地回復と対独復讐であった。英米海洋陣営とは思想的に対立したが、独露大陸覇権の阻止という点で利害が一致する「捻れた関係」にあった。

## 国内対立軸

- **復讐主義（主流）vs 革命的国際主義**: 政権の主流（デア派）は失地回復と対独復讐を最優先する。一方、革命の国際的拡大そのものを目的とする純粋な国際主義派も存在し、復讐主義を「革命の堕落」と批判する。
- **国民サンディカリスト vs 穏健社会主義**: 1920年代の路線闘争で国民サンディカリストが勝利したが、議会主義的社会主義の残存勢力は体制内に潜在し、講和条件の平和的改訂を主張する。
- **革命体制 vs 旧勢力**: 王党派（モーラス派）・カトリック保守派・自由主義者は弾圧・亡命しているが、地下活動や亡命先からの干渉を通じて体制転覆を図る。ゲーム上の分岐（右派・極右ルート）の素地となる。
- **植民地問題**: 革命政権が「反帝国主義」を掲げながらAOC・ALGを従属国として保持している矛盾は、国内外の批判の的となりうる。
