# ドイツ帝国（GER）

## 概要（1936時点）

立憲君主制の帝国であり、皇帝・宰相府・参謀本部と帝国議会（Reichstag）が併存する。
ビスマルク以来の対露協調を国家方針として維持し、ロシア帝国との独露同盟を大陸政策の軸とする欧州の主導国である。

## 前史（POD → 1936）

ドイツ帝国はビスマルク以来の対露協調を国是とし、フランス封じ込めを大陸政策の基軸とした。

- **[独露協調の固定化（第一次モロッコ事件）](../events/1905_first-moroccan-crisis-tangier.md)（1905.3.31）**

  独露協調は「フランス封じ込め」の国家方針として固定化された。一方で英仏協商は反独政治連携へ発展した。

- **[オーストリア＝ハンガリーの離反（ボスニア危機）](../events/1908_austria-hungary-defection.md)（1908.10.0）**
  墺洪のボスニア・ヘルツェゴヴィナ併合に対し、ベルリンは対露協調を優先しウィーンへの全面支持を避けた。

- **[皇帝外交の後退（デイリー・テレグラフ事件）](../events/1908_kaiser-diplomacy-retreat.md)（1908.10.0）**
  デイリー・テレグラフ事件で皇帝の個人的外交が国内外の批判を浴びた。
  ヴィルヘルム2世の威信は傷ついたが、独露協調は皇帝個人の判断から宰相府・外務省・参謀本部が管理する制度的な国家政策へ移行した。

- **[海軍競争と第二次モロッコ事件](../events/1911_second-moroccan-crisis.md)（1911.0.0）**
  第二次モロッコ事件で再び対仏緊張が高まったが、外務長官キーデルレン＝ヴェヒターはロシアとの協調を損なわぬ範囲で交渉した。
  英独海軍対立は深まり、ティルピッツら海軍派が拡張論を強めた。独露同盟は英国海洋覇権への対抗軸としても機能し始めた。

- **[帝国議会と国内対立（1912年選挙）](../events/1912_reichstag-spd-largest-party.md)（1912.1.12）**
  社会民主党（SPD）が帝国議会最大勢力となった。宰相は依然として皇帝に責任を負い、議会多数派は内閣を組織できなかった。
  SPD内部では独露同盟をめぐり、二正面戦争回避の現実外交として黙認する穏健派と、ツァーリズムとの提携を批判する左派が対立した。

- **[ツァーベルン事件](../events/1913_zabern-affair.md)（1913.0.0）**
  アルザス＝ロレーヌでの軍・市民衝突を機に、帝国議会で軍の越権が批判され、軍部と文民社会の対立が露わになった。
  この対立は翌年の開戦時に「城内平和」で一時的に覆われたが、議会改革要求は残り後の1918年改革へつながった。

- **[世界大戦の勃発](../events/1914_great-war-outbreak.md)（1914.0.0）**
  バルカン危機・露墺対立・英独海軍競争・仏独対立が重なり、ヨーロッパは独露伊陣営と英仏墺土陣営の全面戦争へ突入した。

## 国内対立軸

- **君主派（皇帝・参謀本部）vs 議会派（帝国議会）**
  宰相は皇帝に責任を負い、議会多数派は内閣を組織できない。デイリー・テレグラフ事件・ツァーベルン事件で軍部と文民社会の対立が表面化し、1918年の憲法改革要求へつながる。
- **独露同盟をめぐるSPD内対立**
  二正面戦争回避の現実外交として黙認する労働組合系穏健派と、ツァーリズムとの提携を反動的外交と批判する左派（ローザ・ルクセンブルク／カール・リープクネヒトに近い系統）。
- **対外路線：対露協調（フランス封じ込め）vs 英独海軍競争**
  ビスマルク以来の対露協調を軸としつつ、ティルピッツら海軍派が英国海洋覇権への対抗を主張する。
